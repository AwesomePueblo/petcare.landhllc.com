# petcare.landhllc.com

Rachel Higgins Dog Grooming. React (Vite) site with Calendly booking.

Development:
- `npm install`
- `npm run dev` — local dev server
- `npm run build` — builds to `dist/`

Deployment:
- GitHub repo connected to Netlify; every push to `main` auto-deploys
- Netlify build command: `npm run build`, publish directory: `dist`
- Custom domain: petcare.landhllc.com
- Previously hosted on GitHub Pages at petcare.cuemusic.media
